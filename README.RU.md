
# Лёгкий компилятор

## О проекте
Это компилятор для языка программирования Light. Он принимает код на языке Light и преобразует его в C-код, который затем компилируется в нативный бинарный файл.

Я уже некоторое время изучаю русский язык и подумал: почему бы не писать код тоже на русском. Поэтому я сделал этот компилятор, который использую для написания русского кода, работающего нативно.

## Возможности
Компилятор поддерживает базовое объявление переменных, ввод и вывод в консоль. Также поддерживаются стандартные операции: сложение, вычитание, умножение, сравнение и подобные.

## Зависимости
Вам понадобится Clang.  
И всё!

## Сборка
А теперь самое интересное — давайте соберём это.

Из корня проекта просто выполните:

```bash
make release
make install
```

Или

```bash
make rus-release
make install
```

для сборки с русским синтаксисом

Это скомпилирует и установит компилятор в правильную директорию на вашем компьютере. После этого вы можете выполнить:

```bash
make examples
```

Это скомпилирует все примеры Light.

## Использование

Чтобы использовать этот компилятор, выполните:

```bash
lightc <file.свод>
```

Это скомпилирует файл Light в C, а затем скомпилирует C-код в нативный бинарный файл.
